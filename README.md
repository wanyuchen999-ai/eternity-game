# 午夜档案 · 刑侦推理网页小游戏

CCTV 夜视监控氛围的刑侦推理游戏，一案一档、可持续追加新案件。纯前端 HTML + CSS + JavaScript，**无需后端、无需服务器，双击 `index.html` 即可游玩**（建议使用 Chrome / Edge，窗口 ≥ 1080 宽）。

> 文件夹名可自行修改（如改为「午夜档案」），不影响运行，资源均为相对路径。

## 项目结构

```
午夜档案/
├── index.html                 ← 唯一页面主文件（三视图：首页 / 关卡操作台 / 推理结算 + 全部样式与逻辑）
│                                 游戏名称如需修改：搜 index.html 里的「午夜档案」即可
├── js/
│   └── levels.js              ← ★ 所有案件数据都在这里（新增关卡只改这个文件）
├── assets/
│   ├── images/case01/         ← 第一案监控图（已接入第一案实图；cam01–cam04.jpg）
│   ├── images/ui/             ← 首页氛围背景 / 标题 Logo（可替换）
│   └── audio/                 ← 音效文件（当前为占位音效，可直接替换）
├── tools/                     ← 开发辅助工具（游戏运行不需要）
│   ├── make_placeholders.js   ← 重新生成占位图/占位音效：node tools/make_placeholders.js
│   ├── make_title_logo.py     ← 标题Logo白底抠透明：python tools/make_title_logo.py
│   ├── src/                   ← 工具用的原始素材（标题原图）
│   └── dev_server.js          ← 本地预览服务器：node tools/dev_server.js（可选）
└── README.md
```

## 玩法（游戏内也有说明弹窗）

1. 关卡选择页点击案件卡片进入监控室；
2. 左侧 **CAM01–CAM04** 切换摄像头，下方 **时间轴** 在案发前 / 案发时段 / 案发后之间回放；
3. 仔细观察画面，**点击可疑之处即可取证**——线索分三类：**关键物证**（破案必需）、**普通细节**（补全时间线）、**干扰假线索**（误导项，结局统计里会单独列出）；
4. **证词质证**：打开【嫌疑人证词】，点击你认为说谎的片段进行质证——只有手里有对应物证时质证才会成立（矛盾数计入结局判定）；质证不成立或证据不足会当场提示；
5. 【线索笔记】收录全部已取证物证；【时间线】按时间点自动排列线索，帮你拼出完整行动链；
6. 点击【前往推理】回答全部推理问题并提交——结局由 **问题答对数 + 关键物证完整度 + 谎言识破度** 共同判定：
   - **✔ 完美破案**：问题全对 + 关键物证集齐 + 全部谎言识破；
   - **▲ 半推理 · 真相未尽**：锁定真凶，但证据链有缺口；
   - **✕ 推理失败**：错判真凶或被干扰线索带偏。

> 会话内自动记住调查进度（刷新页面即清空，暂无存档功能）。

## 替换美术素材

### 监控图片

1. 把你的图片放入 `assets/images/case01/`（任意格式、任意分辨率，建议统一 16:9）；
2. 打开 `js/levels.js`，把 `images` 中对应路径改成你的文件名即可。
   路径写错或文件缺失时，画面会显示 **NO SIGNAL** 并提示具体路径，不会白屏。

时段区分：当前第一案四个时间点共用一张原图，靠 `times` 里每项的 `filter` 字段
（CSS filter）区分 22:12 / 22:24 / 22:36 的明暗；之后若为各时间点出了独立成图，
把 `images` 里三个键指向不同文件即可，`filter` 可清空。

图内自带 CAM 角标时，给案件加 `camLabelBaked: true` 可隐藏页面左上角的重复角标。

线索坐标换图后需要重新标定：进关卡按 `P` 开启坐标拾取模式即可（见下文）。

线索分级：`clues` 里加 `type: "core"`（关键物证）/ `"decoy"`（干扰假线索），缺省为普通细节；三种类型都会被收集并进笔记，但只有 core 计入完美破案判定。

### 线索坐标

图片更换后，线索点位需要重新标定：

1. 进入关卡，**按 `P` 键** 开启「坐标拾取模式」（画面出现网格与实时坐标读数）；
2. 把鼠标移到线索位置，点击画面，坐标会**自动复制**成
   `{ "cam": "CAM02", "time": "22:24", "x": 68.0, "y": 59.9 }`；
3. 粘贴进 `js/levels.js` 对应线索的 `x / y`（百分比坐标，与图片分辨率无关）。
   再次按 `P` 退出。调试模式下未收集的线索会以虚线圆圈显示，方便核对。

### 首页 / 结算页氛围背景与标题 Logo

`js/levels.js` 顶部的 `UI_CONFIG`：

- `menuBg`：首页 / 结算页全屏氛围背景（当前为占位雨夜街口图），建议 1920×1080；
- `titleLogo`：首页大标题 Logo（透明底 PNG，血溅毛笔字）。置为 `null` 时退回文字标题；
  原图在 `tools/src/title_logo_src.jpg`，白底 JPG 可用 `python tools/make_title_logo.py` 重新抠图。

背景缺失时自动退回内置 CSS 氛围底，Logo 加载失败时自动退回文字标题，均不会白屏。

### 音效

音效路径统一在 `js/levels.js` 顶部的 `AUDIO_CONFIG` 中，替换文件或改路径即可；置为 `null` 可关闭某个音效。文件缺失时自动静音、不报错。触发位置：

| 配置键        | 触发时机                 |
| ------------- | ------------------------ |
| `camSwitch`   | 切换摄像头               |
| `timeSwitch`  | 切换时间点               |
| `clueFound`   | 点击命中线索、取证成功   |
| `panel`       | 打开 / 收起侧边面板      |
| `reveal`      | 推理结局揭晓             |
| `click`       | 通用按钮（开始、返回等） |

## 新增一个案件（不需要碰任何页面代码）

1. 打开 `js/levels.js`，复制文件末尾的「关卡配置模板」，填入新案件内容；
2. 把配置对象追加进 `CASES` 数组（顺序即关卡选择页的排列顺序）；
3. 把新案件的图片放入 `assets/images/你的案件目录/`，并在配置的 `images` 里写好路径；
4. 刷新页面即生效。某个案件未做完时，给它加 `locked: true` 就会显示为「未开放」。

一份配置包含：案件名称 / 摄像头列表 / 每摄像头×每时间点的图片路径 / 嫌疑人证词 /
线索数组（摄像头 + 时间点 + 百分比坐标 + 线索文字）/ 推理问题与选项（每个选项对应
`perfect / partial / fail` 三种结局文案之一）。摄像头数量、时间点数量、线索数量、选项数量均可增减，界面自动适配。

## 常见问题

- **双击打开后没有声音？** 浏览器要求先与页面交互，点击任意按钮后即恢复。
- **画面显示 NO SIGNAL？** 按提示检查 `js/levels.js` 里的图片路径与文件是否一致。
- **想让某条线索更容易/更难点中？** 调整该线索的 `r`（命中半径，图片宽度的百分比，默认 4）。
